# 后台用户与房间管理

入口：https://craftpilot.tolike.cn/admin。继续使用原管理员登录，不改变邮箱配置、普通账号密码规则或联机客户端协议。

## 用户管理

- 搜索邮箱、昵称、用户编号；按正常、停用、最近 5 分钟活动筛选。
- 按注册时间或最近登录排序，每页 10、25、50、100 条。
- 查看注册时间、最近登录、最近活动、有效会话数及当前房间。
- 用户详情可以修改昵称和内部管理备注，启用或停用账号。
- 停用与撤销登录需填写原因；停用立即撤销所有会话，并断开其房间连接，房主被停用时关闭整个房间。
- 撤销全部登录不修改账号密码，用户可以再次使用邮箱密码登录。
- 批量启用、停用、撤销登录，一次最多 50 位。选择范围只限当前页，查询或换页会清空选择；不存在的用户导致整个批次拒绝，避免部分误操作。

有效会话不是在线人数。最近活动指令牌最近 5 分钟有请求或房间心跳，不是精确的设备在线状态。旧记录没有历史活动时间时显示“暂无”，不伪造时间。

邮箱是验证过的登录身份，不提供直接编辑邮箱或跳过邮箱验证的入口。管理界面不显示密码摘要、验证码、会话令牌或 SMTP 凭据，不直接永久删除用户。

## 在线房间

- 搜索房间号、房主昵称、房主编号；按运行中、等待连接、限制加入筛选。
- 按创建时间、人数或累计流量排序，支持分页及 10 秒自动刷新。
- 查看房主、端口、创建时间、人数上限、游戏连接数、存续时间、累计上/下行及最近转发时间。
- 详情显示成员身份、连接状态、加入时间、最近心跳，以及各条游戏连接状态和流量计数。
- 限制新成员加入，不影响已经加入的成员；撤销待加入票据，无法用旧票据绕过。
- 修改房间容量为 2 至 8 人，不能低于当前人数；关闭房间断开所有控制与游戏连接。
- 踢出普通成员，可同时禁止其再次加入本房间；加入限制支持解除。房主不能单独踢出，需要关闭房间。
- 可以只断开某条 TCP 游戏连接，保留用户房间成员身份。

踢人与停用用户会立即撤销票据和游戏连接，不等待心跳定时器。房间或连接已消失时返回明确错误，不把无效操作记为成功。

统计不保存转发内容，只计数。房间、连接、加入限制与流量仍是内存状态，服务重启后关闭并清空；管理操作日志在数据库中持久化。

## 审计与安全

操作日志记录后台动作、目标、时间和填写的原因，保留 180 天，不记录密码、令牌、验证码、SMTP 授权码或流量内容。账号备注和日志在服务重启后保留。当前后台只有一个管理员身份，日志不假装区分不存在的多管理员角色。

所有管理 API 要求管理员会话；写操作继续校验 Origin 和 CSRF。查询值经过校验，SQL 使用绑定参数，排序只使用白名单字段。批量用户更新在事务中执行。

## 接口

- `GET /api/admin/users?q=&status=all&page=1&pageSize=25&sort=newest`。
- `GET /api/admin/users/:id`，`PATCH` 可修改 `nickname`、`note`、`disabled`、`reason`。
- `DELETE /api/admin/users/:id/sessions`，请求包含 `reason`。
- `POST /api/admin/users/batch`，包含 `ids`、`action`（`disable`、`enable`、`revoke`）、`reason`。
- `GET /api/admin/rooms?q=&state=all&page=1&pageSize=25&sort=newest`。
- `GET /api/admin/rooms/:code`，`PATCH` 包含 `locked`、`capacity`、`reason`，`DELETE` 包含 `reason`。
- `DELETE /api/admin/rooms/:code/members/:id`，包含 `reason` 和可选 `block`。
- `DELETE /api/admin/rooms/:code/blocked/:id`，`DELETE /api/admin/rooms/:code/connections/:id`，均包含 `reason`。
- `GET /api/admin/audit?q=&page=1`。

所有删除请求仍使用 JSON 请求体。详情仅返回管理需要的安全字段，不包含任何原始凭据。
